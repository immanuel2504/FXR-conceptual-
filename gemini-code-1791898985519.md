# Zebra IoT Connector (ZIoTC) Technical Documentation

## 1. Product & Architectural Foundations
   ├── 1.1 Architectural Overview & Core Value
   │     • Purpose: Edge-native Auto-ID telemetry without intermediate middleware
   │     • Supported Hardware: FX7500, FX9600, FXR90 (Ultra-Rugged), ATR7000 (RTLS Array)
   │     • Firmware Baseline: Version compatibility matrix and feature prerequisites
   ├── 1.2 The Four Core Functional Interfaces
   │     • Management Interface (Synchronous reader configuration and firmware control)
   │     • Control Interface (Synchronous read operation triggers and mode selection)
   │     • Data Interface (Asynchronous real-time RFID tag event streaming)
   │     • Management Events Interface (Asynchronous health, heartbeats, errors, and GPIO)
   ├── 1.3 Topology & Deployment Models
   │     • Pure Cloud Deployment: Direct egress to AWS IoT Core / Azure IoT Hub / HiveMQ
   │     • On-Premise / Local Deployment: Local MQTT brokers and HTTP/REST webhooks
   │     • Hybrid Deployment: Cloud management/control paired with local edge data processing
   └── 1.4 Network Protocol & Firewall Port Specification Matrix
         • Inbound: Port 80 (HTTP), 443 (HTTPS Web Console / REST API)
         • Outbound: Port 1883 (MQTT TCP), 8883 (MQTT TLS), 8443 (HTTPS POST Webhooks)
         • Infrastructure: Port 123 (NTP Time Sync), 53 (DNS), 514 (Syslog)
