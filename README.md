# FXR60 / FXR90 conceptual documentation

Conceptual documentation for the Zebra FXR fixed RFID readers. It explains what the IoT Connector is and how to work with it. The two files next to this page are the contracts:

- `FXR_60-90_mqtt_api.json` — IoT Connector MQTT API (FXR readers), version 1.0.0
- `FXR_60-90_rest_api.yaml` — IoT Connector REST API (FXR readers), version 3.0.0

Command fields, response codes, and schemas stay in those files. These pages explain the model those files describe.
